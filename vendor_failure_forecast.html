What this does not show

    Which inputs move forecasts overall

    Average size of each input’s contribution across all 6,978 training vendor-weeks, on the log-hazard scale. This is the model’s overall behaviour. For a single vendor-week, the What-if tab breaks that one forecast down separately — a different question, and often a different ordering. Size here means influence on the forecast, not evidence that an input causes failures.

    The 13-week rejection rate contributes almost nothing: its fitted coefficient is 0.0004. It is kept because dropping it changed nothing, and removing inputs after seeing the holdout would overstate how well the model was specified in advance.

    Why this vendor-week scores what it does

    Contributions to this one forecast, not the model’s overall behaviour — that is on the Model performance tab. The model is linear in its link, so these are exact Shapley values on the log-hazard scale: they add up to the distance from a reference vendor-week whose inputs are all at their training averages. The running chance column walks the same path in probability terms, in the order shown; probabilities do not add, so read the order as one route to the number, not as a ranking.

    A contribution says how much an input moved this forecast. It does not say that changing the input would change the outcome.

    Where this vendor would land on that week's review list

    The weekly review list, and how sure we are of it

    Each Monday the model scores every vendor with recent deliveries and ranks them by expected cost of a failure next week. The top of the list, as many vendors as the week's review capacity, is what the manager reviews. Vendors already under corrective action are held out.

    i"In list" is the share of 600 draws from the model's uncertainty in which the vendor makes the top of the list. 100% means it is in regardless of which plausible version of the model is true; 50% is a coin flip. Capture is graded with hindsight: it uses next week's real failures, which the model never saw.
